# sbatra24.github.io

Personal site, live at https://sbatra24.github.io. Plain HTML, CSS and JS. Nothing to build.

- `index.html` has all the content.
- `style.css` is the look. `main.js` runs the hero grid (click to draw on it), the section pie, the rain, the jump palette (cmd+K), the project charts, scroll reveals and the photo gallery layout.
- `img/` holds the photos as `01`-`10` in AVIF and JPEG, plus the evalsniff training curve.
- `fonts/` is Archivo and Geist Mono (both OFL), self-hosted.

Push to `main` and GitHub Pages serves it within a minute or two.
